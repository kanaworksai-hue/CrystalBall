# CrystalBall Studio

一个竖版优先的水晶球影像项目。页面包含底层普通媒体展示、上层水晶球鱼眼/反射效果、最多 5 个水晶球媒体素材、文字编辑、多语言界面、移动端滑动切换和桌面羽毛鼠标。

## 运行

```bash
node server.mjs
```

打开 `http://localhost:4173`。

## 功能

- 上传图片或视频作为水晶球内容，最多 5 个。
- 上传单独的底层展示媒体，也可以同步当前水晶球素材。
- 左右触摸滑动或鼠标拖动切换水晶球内容。
- 桌面端预览区域使用羽毛光标。
- 标记固定为 KanaWorks_AI，标题和标题大小可编辑。
- 支持中文、英文、日文界面切换。
- 鱼眼、反射、球面缩放可调，鱼眼支持负值内凹和高强度夸张效果。
- 水晶球大小、X/Y 坐标和坐标系拖拽可调。
- 可折叠编辑面板，带兔子图标按钮。
- 包含 KanaWorks_AI 的 X 链接。
- 配置和上传素材会保存到浏览器本地。

## 素材

默认图片来自 `public/assets/crystal-forest.png`。
默认视频来自 `public/assets/sample-crystal.mp4`，已转码为网页友好的 H.264。
