# CrystalBall Studio

[日本語](#日本語) | [English](#english) | [中文](#中文)

## 日本語

CrystalBall Studio は、スマートフォンの縦画面を中心に作られた水晶玉ビジュアル編集ページです。下層に通常の画像または動画を表示し、上層の水晶玉には魚眼、反射、球面表現を重ねます。

[公開ページを開く](https://kanaworksai-hue.github.io/CrystalBall/)  
[詳しい使い方を見る](docs/usage.html#ja)

### 機能

- 水晶玉素材として画像または動画を最大 8 個までアップロードできます。
- 下層表示用の画像または動画を別にアップロードできます。
- スマートフォンでは左右スワイプ、PC ではドラッグで水晶玉素材を切り替えます。
- PC ではプレビュー上のカーソルが指アイコンになります。
- タイトルとタイトルサイズを編集できます。
- 魚眼強度は負値の内凹表現から、強い誇張表現まで調整できます。
- 反射、下層ベール、球面ズーム、水晶玉サイズ、X/Y 座標、座標パッドを調整できます。
- 編集パネルはウサギボタンで開閉できます。
- UI は日本語、英語、中国語に対応しています。
- `want more? follow me` から KanaWorks_AI の X アカウントへ移動できます。

### ローカル実行

```bash
node server.mjs
```

Open `http://localhost:4173`.

## English

CrystalBall Studio is a portrait-first visual editor for mobile users. It shows a normal media layer underneath and a crystal ball layer above it with fisheye distortion, reflection, and spherical glass styling.

[Open published page](https://kanaworksai-hue.github.io/CrystalBall/)  
[Read the user guide](docs/usage.html#en)

### Features

- Upload up to 8 images or videos as crystal ball media.
- Upload a separate lower-layer image or video.
- Swipe on mobile or drag on desktop to switch crystal ball media.
- On desktop, the preview cursor appears as a finger icon.
- Edit the title and title size.
- Tune fisheye from negative concave distortion to exaggerated positive distortion.
- Adjust reflection, lower veil, sphere zoom, orb size, X/Y coordinates, and the coordinate pad.
- Hide or show the editor with the rabbit button.
- UI languages: Japanese, English, and Chinese.
- Use `want more? follow me` to open KanaWorks_AI on X.

### Run Locally

```bash
node server.mjs
```

Open `http://localhost:4173`.

## 中文

CrystalBall Studio 是一个面向手机竖屏用户的水晶球视觉编辑页面。它下方显示普通图片或视频，上方水晶球叠加鱼眼、反射和球面玻璃效果。

[打开公开页面](https://kanaworksai-hue.github.io/CrystalBall/)  
[查看使用说明](docs/usage.html#zh)

### 功能

- 最多上传 8 个图片或视频作为水晶球素材。
- 可以单独上传底层展示图片或视频。
- 手机左右滑动、电脑鼠标拖动即可切换水晶球素材。
- 电脑端预览区域会显示手指光标。
- 可以编辑标题和标题大小。
- 鱼眼强度支持负值内凹，也支持正值夸张放大。
- 可以调整反射、底层遮罩、球面缩放、水晶球大小、X/Y 坐标和坐标系拖拽点。
- 编辑面板可以用兔子按钮收起或展开。
- UI 支持日文、英文、中文。
- 点击 `want more? follow me` 可以打开 KanaWorks_AI 的 X 账号。

### 本地运行

```bash
node server.mjs
```

打开 `http://localhost:4173`。
